# 主要研究问题

更新：2026-11-11。以下是当前需要检验的问题和拟议方法，均不冒充已完成实验的结论。现有收益和限制见[最新实验结果](latest-experiments.md)。

## 主问题 细纹幅度与真实结构为何不一致

当前已测到附加桥和重采样的细频衰减；最终感知指标改善，但部分檐口、笔画的连接和排列仍有错误。需要区分三种原因：LR 本来难以辨别真实结构；生成模型采用的统计决策与目标不同；已经可用的结构证据在生成、解码或后处理中丢失。

幅度、相位、位置和拓扑分别测量。频带能量接近 HR 不保证笔画位于正确位置；LPIPS 下降也不能裁决细节是否真实。A10 的端点读出失效说明当前测量方法不足以区分这些原因，后续结构诊断先完成读出资格，再进行阶段因果对照。

## 方向一 双专家特征输运的空间对齐

**问题：** 当前 RGB 配准能否由特征空间的同位置输运替代，减少错配和重采样损伤？

**拟议实现：** 原生专家取冻结解码前缀特征 f，视觉专家取同一 LR 的视觉估计 v14 及其浅层特征。轻量投影器建立共同的 128×128 LR 锚定网格，在多尺度局部相关体上从粗到细预测二维偏移与置信度。输运只作用于特征，低信度位置走原生恒等路径，再用带符号细节头读出修正；首轮只训练新增头部。

**最小对照：** 无输运、现行 RGB 配准、固定几何输运、学习特征输运；加入已知位移、遮挡和错位特征。先测位移终点误差、错配率、信度及边界外溢，再测同位置带符号频带相关、边缘/骨架 F1 和图像指标。按父场景聚类，提前固定配准容差。

## 方向二 单种子细节读出是否需要两次解码

**问题：** 桥前 decoder_suffix(f) 和桥后 decoder_suffix(f+delta) 的第二次后缀解码，对最终收益是否必要？

**拟议实现：** 对照 A 保留当前双解码；候选 B 只解码原生 f，轻量头从 f、delta 和 LR 预测两层 Haar 的带符号细节系数，最粗低频直通；候选 C 只解码纠正特征，再用同预算头预测原生参考的细节差。先在历史单种子读出隔离比较，再接入当前完整链条。教师双解码可用于训练，推理成本按实际调用计数。

**判据：** 同父场景、同种子与同训练预算，比较画质非劣、边缘/骨架、细频幅相、实际解码次数、端到端时间和显存。非劣容差与效率目标须在确认前固定，不能以单个感知指标替代真实结构证据。

## 方向三 真实相机反馈的跨设备泛化

**问题：** 如何让反馈同时适用于不同设备和真实数据集？历史反馈在 RealSR 上有收益，但迁移至 DRealSR 时出现 PSNR 改善、LPIPS 均值变差的取舍。

**拟议实现：** 从 LR 估计空间变化的模糊、采样偏移、颜色、噪声和不确定性，构成共享 HR→LR 前向相机算子。反馈头读取预测与实际 LR 的残差，由观测信度控制反馈，低信度时收缩到固定块均值投影。

**泛化评价：** 按设备、父场景和拍摄序列分组，相机留一与数据集留一为主：RealSR→DRealSR、反向迁移及协议兼容的第三真实基准。先统一颜色、裁切和配准口径；每个目标设备的权重、强度和阈值在看确认集前冻结。比较无反馈、块均值、历史相机反馈、共享算子及信度门控，报告设备最差组、结构与 LR 重投影残差。

## 工作顺序与证据要求

先建立有效结构读出并诊断空间对齐，再独立裁决解码必要性，最后做相机留出评价。各方向使用当前 v1.5 为共同参照；单项成立后设计组合消融。训练、开发与确认按父场景和设备隔离；确认集不用于反复挑选配置或改成功标准。

方法参照：[VOSR](https://openaccess.thecvf.com/content/CVPR2026/html/Wu_VOSR_A_Vision-Only_Generative_Model_for_Image_Super-Resolution_CVPR_2026_paper.html)、[EDVR](https://arxiv.org/abs/1905.02716)、[RealSR](https://openaccess.thecvf.com/content_ICCV_2019/html/Cai_Toward_Real-World_Single_Image_Super-Resolution_A_New_Benchmark_and_a_ICCV_2019_paper.html)、[DRealSR](https://www.ecva.net/papers/eccv_2020/papers_ECCV/html/471_ECCV_2020_paper.php)。文献提供方法和数据集背景，以上三个结构是本项目的后续提案。
