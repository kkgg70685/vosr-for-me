# VOSR v2.5：从生成图像到可用几何

2026-11-13 · 实现身份 `2.5.0-prototype` · 当前为可运行研究原型，无自然图性能结论。

## 1. 研究判断与仓库结构

本轮推荐的问题是：**生成式超分能否在保留材质的同时，让跨图像对应关系更准确，并让几何修改只沿 LR 能约束的方向发生？** 它将超分输出接入图像匹配、定位和三维重建，而不止于单图识别或视觉诊断。

主仓库 `kkgg70685/vosr-for-me` 的 main 为 `5b116bd5f8f998f708c3b265f822b52a40cb668a`，保留 v1.5；v2 位于另一分支。此次新分支 `codex/vosr-v2.5-observable-transport` 直接以 main 为父，不把尚未合并的 v2 整包复制过来。

| 层级 | 已有职责 | v2.5 处理 |
| --- | --- | --- |
| 冻结 VOSR / DINOv2 / 解码器 | 从 LR 生成原生图 | 保留原生 Euler/CFG 运行约定，一次生成 |
| material_direction_flow 等 | 历史双轨与材质约束 | 作为 v1.5 来源保留 |
| texture_retention / visual_evidence_texture | 分频、跨尺度视觉纠错 | 保留旧基线，不叠入新核心 |
| native_anchor_bridge | v1.5 原生与视觉分频融合 | 仍可独立对照；其 A9 结果不是 v2.5 结果 |
| structure_observation_v2（另分支） | 栅格图候选、观测筛选、潜速度适配、接受门 | 学习失败经验，不依赖旧头和适配器 |
| observable_transport_v25 | 连续几何求解与显式执行 | 本次新增完整推理和评价路径 |
| configs / provenance / tools | 运行身份与来源 | 新协议、新来源表；旧 50 文件保持散列 |

主工作区的科学主线、研究、数学建模、实验、审查、绘图和研究者文件是职责分区；`kimi协作实验` 中的嵌套 Git 仓库是当前代码事实来源。本报告的指定阅读副本在研究者文件中。

## 2. 哪些旧经验真正影响设计

用户提供的《VOSRv2.5_设计前证据总结.md》是证据资料，内部建议不自动等同于本轮指令。它比部分旧导航页更晚、更审慎；本轮优先采用其修正口径，但未重新获取服务器原始表，因此历史数字不是本次独立复算。

- ±0.25 HR 像素命令曾在 raster 中与零相同：改用浮点坐标和连续场，不经取整。
- 适配器在受限域有非零输出，却无正负命令响应：执行改为定义明确的坐标映射。
- 矩形局部位移造成整条结构弯折：不用矩形裁剪拼贴；使用全图平滑场。但“平滑”仍不等于“整条结构刚性”，这一问题保留为真实限制。
- 旧灰度相位读数失效：核心求解使用 RGB 成像残差，不把一个灰度相位当真值。
- 96 例中的 34/55 等结果尚待修正读数重评：不把它们当 v2.5 性能下限。
- 整结构平移只验证执行：必须单独比较真实 LR 求解与给定命令执行。
- 最终全拒会掩盖门前行为：保留 native、最后尝试 revised、已接受 final，以及全体分母。

## 3. 发散与收敛：十个候选

| 候选 | 价值与数学依赖 | 本轮取舍 |
| --- | --- | --- |
| 观测可辨识子空间中的连续形变 | 逆问题、谱分解、干扰参数剔除；区分可执行与可恢复 | 主实现 |
| 为图像匹配/位姿服务的超分 | 投影几何、SE(3)、对应误差与位姿 AUC | 首选应用；当前先实现单应评价 |
| 多视图一致的超分与 3DGS | 极几何、可见性、辐射场 | 高价值后续，需要真实多视图资产 |
| 拓扑修复与缺失笔画生成 | 图编辑、持久同调、离散/连续混合推断 | 连续形变无法完成；单独方向 |
| 相机不确定性商空间 | Fisher 信息、Schur 补、不可辨识等价类 | 当前仅剔除颜色；空间相机干扰待扩展 |
| 频率相位与材质联合恢复 | 多通道圆统计、相位解缠 | 周期歧义强，不作通用主干 |
| 逆问题中的条件生成分布 | 后验采样、校准集合、覆盖风险 | 与单种子要求不匹配，不作核心实验 |
| 可辨识几何教师蒸馏 | 摊销优化、受约束蒸馏 | 求解层先有增量再训练快网络 |
| 文本/文档结构保持超分 | 图结构、字符布局、OCR 编辑距离 | 可做小领域，但偏向识别且竞争密集 |
| 遥感线网/工业计量 | 图连通、几何尺度、拓扑误差 | 可落地，但标注/成像要求较高 |

前三个收敛方向是：可辨识连续形变、几何匹配、相机不确定性。当前实现第一个，给第二个建立执行评价入口，并明确第三个的数学位置。不把所有候选堆成一个模型。

## 5. 完整机制与高级数学依赖

记 LR 为 y，冻结原生图为 x₀，相机为 A，几何系数为 a。B 是全图平滑余弦基；默认每方向 3×3 个模式，共 18 系数。系数和速度均以 HR 像素计。

$$
x_0=G(y; s=6),\qquad v_a(p)=\sum_k a_k B_k(p).
$$

### 5.1 Lie 群视角下的坐标执行

连续理想模型中，平滑 Lipschitz 速度场的流在适当完整域与边界条件下存在唯一可逆映射。为使正命令对应内容右移/下移，图像采用反向采样：

$$
\phi_a=\exp(-v_a),\qquad x_a(p)=x_0(\phi_a(p)).
$$

代码采用 6 次缩放平方、双线性插值、border 延拓。常量速度的内部区域是精确定义的平移；离散插值仍可能衰减纹理。只在零速度时显式返回原图副本，保证逐元素恒等。

**边界：**连续流的可逆性不能直接转移为离散栅格的全局拓扑保证。代码检查离散 Jacobian 最小值和逆复合误差，并限制速度峰值；这些是数值筛选，不是拓扑恢复定理。全图场也不能新增缺失内容或分开粘连结构。

### 5.2 可变投影、Schur 补与颜色干扰

成像残差中，每通道允许增益和偏置；它们只用于观测比较，不改变最终输出 RGB。固定有效 LR 裁边后，构造每通道两列的设计矩阵。

$$
p(a)=A(x_a),\qquad C_c(a)=[p_c(a),\mathbf{1}],
$$
$$
\beta_c^*(a)=C_c(a)^+y_c,\qquad r_c(a)=C_c(a)\beta_c^*(a)-y_c.
$$

`+` 表示 Moore–Penrose 广义逆，代码使用秩容忍 SVD 伪逆。各候选都按同一个参数化重新拟合，这是可变投影的 profile objective，不是 v2 的共同前景代理。其代价是增益/偏置可能吸收部分几何证据。

在局部线性模型中，将几何 Jacobian Jg 与干扰 Jacobian Jn 联立，再消去干扰，得到：

$$
P_{\perp n}=I-J_nJ_n^+,\qquad H_{\rm eff}=J_g^T P_{\perp n}J_g.
$$

这是 Schur 补/商空间的入口。实际代码对**重新拟合后的整个残差函数**作中心差分，包含投影算子随 a 变化的效应。不能在非零残差时声称其 Jacobian 严格等于固定的 P⊥n Jg。当前只消颜色干扰，未剔除相机位姿/PSF 不确定性。

### 5.3 局部谱可辨识性与稳定逆问题

令 N 为有效 RGB 观测数，归一化 Jacobian 为 J。

$$
J_{:,k}\approx\frac{r(a+\epsilon e_k)-r(a-\epsilon e_k)}{2\epsilon\sqrt{N}},\qquad
J=U\,\mathrm{diag}(s_i)V^T.
$$

默认 ε=0.125 HR 像素。观测模型误差尺度 σ=2/255，关心的系数分辨率 δ=0.25 HR 像素。保留方向满足：

$$
s_i\delta>\sigma.
$$

这是以 RMS 观测变化为尺度的局部灵敏度条件，**不是**置信度、统计显著性、后验方差或 Cramér–Rao 下界。若要进入 Fisher 信息理论，需要估计相关噪声协方差并用 Σ⁻¹ 白化；当前代码未实现，不能以“高级数学”名义冒充。

截断与阻尼更新为：

$$
\Delta a=-V\,\mathrm{diag}\left(\frac{s_i\,\mathbf{1}[s_i\delta>\sigma]}{s_i^2+\lambda}\right)U^T\frac{r(a)}{\sqrt{N}}.
$$

数值实现再限制每步速度峰值，尝试固定 1、1/2、1/4、1/8 四个步长。仅当 profile 残差严格下降且离散形变检查通过才接受，最多三轮。这里的固定回溯是优化算法步骤，不是围绕测试集调参。

### 5.4 能证明什么，不能证明什么

1. 若某个归一化残差 Jacobian 的右奇异方向低于截断条件，则**本次线性更新**在该方向上的系数为零。由于后续 Jacobian 会变化，这不是整条非线性轨迹的全局不变性。
2. 若本轮全部方向被截断，则停止并保留当前已接受结果；若第一轮即全部截断，则精确保留 native。平坦常量输入测试覆盖后一出口。
3. 每次接受都显式比较实际重新拟合残差，所以在相同裁边/相机/目标下，接受序列的该目标值单调下降。这不蕴含 HR 误差单调下降。
4. 不同 HR 可以有相同 LR。任何仅以 LR 为输入的确定性方法都无法对该碰撞中的所有真值同时正确。零空间中保留 native 只是克制更新，不是认证 native 正确。

### 5.5 面向三维的下一层数学

单应关系适用于平面或相机纯旋转等情形；一般三维须使用极几何、基本/本质矩阵和 SE(3) 位姿。后续可比较固定 LightGlue 下的旋转/平移角误差 AUC@5°/10°/20°，但必须有合格标定/位姿来源。循环匹配一致不等于真实几何；不能用无标定的自洽性替代位姿准确率。

## 6. 最小可证伪实验与停止条件

一个固定生成种子、一份冻结协议、四个结构对照：native；仅全图平移；相同平滑场但无观测谱筛选；完整 v2.5。同一 native 被所有方法复用，不搜索“幸运种子”。

首先在内存解析测试确认正负/亚像素执行、色差干扰、平坦碰撞和拒绝行为；再在服务器用既有图像或任意可合法使用图像构造已知单应关系。它不要求人工标注，不绑定某个特定数据集名称。自然多视图留作外部确认，不能把单应测试夸大为三维结论。

如果完整模型不优于同预算普通平滑配准，应承认可辨识筛选无增量；若只优于 native、却不优于仅平移，则不保留复杂场作为贡献；若下游匹配改善而 DISTS/LPIPS 恶化，报告权衡，不用合成总分隐藏。若所有样本不动作，则报告机制未激活，不宣布“安全有效”。

当前不增加生成补偿头：尚无实验证据证明它必要。未来若确认亚像素重采样损失，才考虑在固定几何的材质坐标中做残差补偿，并重复几何任务评价。
