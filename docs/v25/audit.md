# VOSR v2.5 结构审计、修复与真实模型冒烟

日期：2026-11-14。审计起点 `b090715`，修订版 `2.5.1-audit`，协议 R1。**实现和评价链路已跑通，但目前没有证据支持“几何对应更准确”的核心贡献。** 结果是历史开发样本上的冒烟，不能作为独立测试集结论。

## 1. 已修复的问题

| 问题 | 风险 | 修复与证据 |
| --- | --- | --- |
| RGB profile 允许负增益及无界放大 | 反相纹理可被拟合成低残差，破坏几何证据含义 | 中心化回归，正增益固定 [0.5,2]；平坦通道安全处理；反相反例测试 |
| 评价入口依赖8bit缓存native | 与浮点修订或浮点推理结果混表时比较口径不一致，生成身份无法追溯 | 新 `benchmark.py` 现场生成一次浮点base，四方法共享；浮点IQA/PSNR统一范围；PNG统一用于显示与匹配 |
| 推理封装未对父模块调用eval、随机噪声dtype未显式匹配 | 部分子模块状态或精度可能与原生路径不同 | 显式eval/freeze、继承cond dtype；真实原始 `base.sample(...cfg=-.5)` 与新封装逐值一致，最大误差0 |
| 非法单应矩阵未统一按失败处理 | 全零或NaN估计可能污染统计或中断 | 估计矩阵形状、有限性、秩检查；失败仍留AUC分母 |
| JSON通过文本替换处理Infinity | 样本名称也可能被修改 | 递归处理数值，保留字符串；回归测试 |
| 回溯中重复积分/渲染，尝试过程留存不足 | 浪费计算，难追溯拒绝原因 | 复用已渲染RGB与逆检查中的后向位移；记录全部线搜索尝试，不改变接受条件 |
| 缺失完整模型评价、浮点阶段和纹理图 | 无法核对base、修订效果或插值损伤 | 新增 `prepare.py`、`benchmark.py`、`artifacts.py`；保存float stages、整图、统一高频图、编辑区图、CSV/HTML |
| 正式测试无身份和父图交集约束 | 开发/确认泄漏，配置悄悄变化 | test要求显式排除列表、清单/协议SHA、至少32父图、HR、LPIPS/DISTS；相机清单与CLI必须一致 |

增益范围是明确约束而非相机统计校准；它防止负增益反例，不证明颜色干扰已完全消除。测试身份检查只能检查提交的清单，无法自动证明历史排除表完整。

## 2. 结构审计结论

求解层只接收 LR 与native；HR和单应真值未进入推理。18维余弦速度场、缩放平方积分、直接采样同一native、每轮重拟合颜色残差、归一化有限差分SVD、固定三轮/四档回溯与离散检查在代码上对应设计。原生材质不是经过每轮重复RGB重采样：每次候选都从同一native采样。

仍有实质限制：全图低频场可能耦合不同物体；有界颜色拟合仍会吸收几何信息；相机失配可被误当位移；双线性RGB采样会衰减高频；离散Jacobian与逆误差不能证明全局可逆；本模型不能增删缺失结构。没有把这些限制改名成已解决的数学保证。

默认谱门槛为 0.031372549，来自固定的观测尺度2/255除以目标分辨率0.25，并不是实际噪声校准。两张自然图最大奇异值约0.031106和0.024423，均低于门槛，因此全部拒绝。这是当前模型的科学局限，不是通过降低门槛“修复”软件bug的理由。本轮保持门槛不变，没有围绕结果调参。

## 3. 已完成验证

- Windows CPU 与 Linux服务器CPU均通过20项测试：原12项，加反相纹理、增益边界/平坦输入、JSON字符串保真、坏单应失败、共同高频显示、父图泄漏拒绝、安全回退、非恒等构造坐标检查。
- 真实服务器 RTX 5090、PyTorch 2.8.0+cu128；冻结VOSR、真实相机、LPIPS与DISTS权重全部实际调用成功。
- seed=6、guidance=-0.5、25步下，新生成封装与原始FrozenVOSR输出逐值一致；输出1×3×512×512且有限。此处base为仓库历史配置，不是上游官方默认参数。
- 两张自然图与六张构造视图均完成四方法端到端评价；四对非恒等单应完成SIFT/RANSAC评价。
- 两次完整冒烟分别约6.21秒、18.31秒（不含加载权重；后者不含最后SIFT/HTML步骤）；本进程PyTorch峰值分配约3.26 GiB。自然图平均生成约2.09秒/图，构造图约1.92秒/图。共享服务器上的短跑时间不是稳态吞吐基准。
- 已生成8张整图比较、8张主ROI高频图、6张编辑区域高频图；两份HTML与CSV存在。浮点结果及完整日志留服务器。

## 5. 已知几何冒烟：2父图、6视图、4对

从同两个历史父图先构造HR视图再面积降采样；采用显式合成相机，不能与上表合并。AUC为parent macro，数值范围0到1。

完整v2.5更新6/6张，PSNR约增加0.840 dB，但AUC@3下降约0.426个百分点。无谱筛选组图像指标更好，匹配下降更明显。HF_RMS从base的0.033445降到v2.5的0.030028，约下降10.2%；这与重采样平滑一致，但当前证据不能把全部变化归因于平滑，也不能把能量下降当成质量结论。

**当前支持的判断是“链路可运行，存在像素/感知与对应精度的权衡”；不支持“谱筛选带来更好的几何匹配”。** 四对样本不足以推断总体优劣。研究下一步应解释这一反例，再按固定开发/独立确认协议验证，不能只挑PSNR表作为论文结论。
