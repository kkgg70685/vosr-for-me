# 项目状态

更新：2026-11-11。当前模型为 **v1.5 原生结构基础与选择性视觉纠错**。仓库同步现行推理实现及依赖源码；下一阶段三个方向处于研究构想状态。

## 当前实现

冻结 VOSR 0.5B 多步模型、官方轻量解码器、DINOv2 与既有相机资产。原生与视觉引导轨迹共享前 16 步，随后分别继续生成。

1. 原生结构路径读取双门桥之前的 RGB。九候选匹配估计位移，中频配准；细频只在匹配改善超过 0.10 且位移超过 0.75 像素时使用 bicubic 重采样，其余位置保持原生网格。
2. 轻量原生结构头读取 LR、同图视觉预测与原生细节，输出频带纠正门及带符号 RGB 子像素残差，形成估计 N。
3. 视觉路径复用相机读出、四门纹理恢复和同图跨尺度预测，形成校准估计 C。
4. 最终以 N 为基础，把 C−N 分成低、中、细频纠错。当前配置为 `bridge=none`、`method=conf`、`spec=[0.6,0.5,"evidence"]`。

当前单图入口是 `src/native_anchor_bridge_261109_v1/code/infer_system.py`。代码中的原生路径绕过额外平滑桥；视觉校准分支仍复用历史桥资产。这里的局部门描述与 LR 条件预测的一致性，不等同于真实 HR 细节的正确概率。

## 当前证据边界

当前 v1.5 是精度、感知和结构之间的平衡配置，不能称为所有场景、种子、指标严格一致改善的模型。历史 E 集已经参与评价；新增 T 父场景与本轮部分读出训练父场景分开，但上游相机模型可能接触过官方 T 数据，因此不把这些结果统称为全链路从未暴露的独立测试。

PSNR、LPIPS、DISTS 的改善不直接证明缺失笔画或正确高频相位恢复。现有檐口、窗格和字形读数呈现不同变化，结构恢复需位置、边缘、骨架、相位等证据共同支持。
